# Security

If you find a security problem in Elenz (the site at https://elenz.co.nz, its Worker or its data jobs), please tell us
privately rather than in a public issue:

- use **Report a vulnerability** on this repository's Security tab, or
- email hello@elenz.co.nz.

Say what you found and how to reproduce it. We'll reply within a few days and let you know when it's fixed.

Elenz has no user accounts: the site is static, settings stay in your own browser and the analytics are cookie-free
(see https://elenz.co.nz/privacy). The keys the data jobs use are kept in GitHub and Cloudflare secrets, never in this
repository.

For wrong figures or other problems with the site, use "Report a problem" at the foot of any page.
